# Gap report template (sent after Week 0)

**This is a client-facing template. The report speaks to the client as "you".**
Notes marked "For Kristin" are for you only. Delete them before you send the report.

**Version:** draft 1, 4 October 2026.
**Agrees with:** `context/founder-profile.md`, `business/offer-and-pricing.md` (tier contents and caps), `program/6-week-programme.md` (week numbers, topics and swaps) and `program/gap-analysis-framework.md` (how you score the gaps).

---

## For Kristin: how to use this template

- **Fill it from:** the intake form, your requirements matrix and your Week 0 call notes (`program/gap-analysis-framework.md` §3-7).
- **Length:** aim for 3 to 4 pages. The programme file asks for about one page per gap type. Short is kind. The client will reread it.
- **Language:** write it in the language the client chose for sessions.
- **Scores:** write them as words, never numbers: none, small, medium, large (`program/gap-analysis-framework.md` §7.3).
- **Send it:** within [REPORT-TURNAROUND] of the Week 0 call, and before Session 1. You walk through it in Session 1, minutes 5-20.
- **Before sending,** run the quality check in `program/gap-analysis-framework.md` §11.
- **Curly brackets** `{like this}` are filled per client. **Square brackets**, such as [LINKEDIN-URL], are open decisions, filled once.
- **Other versions** are at the end: the single-service gap analysis report, and the Lighter package versions (paused since 29 October 2026).
