# Mode: compare (rank several jobs)

1. Make sure each job has an evaluation report. If not, run triage on each first and full evaluation on the ones that pass.
2. Build one table: job, employer type, verdict, total score, then each weighted dimension, deadline, effort needed (form, test, letter).
3. Rank by score, then break ties by: deadline (sooner first), funding security, effort.
4. Recommend an order of work for the next 1 to 2 weeks that fits the client's urgency and the coach's capacity.
5. Flag duplicates of effort (for example two UN posts that can share one tailored master profile).
