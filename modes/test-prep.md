# Mode: test-prep (written tests and assessments)

Written tests are far more common in this sector than in corporate hiring. Uses `library/interview-and-tests/ngo-written-tasks-and-tests.md`, `embassy-and-donor-processes.md`, `un-competency-based-interviews.md` and `sector/research/03`.

## 1. Identify the test type

| Type | Common for | What is scored |
|---|---|---|
| Technical written test (timed) | UN P and NO posts, INGO technical roles | Technical knowledge, analysis, structure, writing under time |
| Proposal or concept note section | Programme, grants, business development | Logic (problem, objectives, activities, indicators), donor fit, budget sense |
| MEAL task | MEAL roles | Indicators, logframe, data collection plan, analysis of a dataset |
| Situation report or briefing note | Humanitarian, coordination, comms | Clarity, prioritisation, accuracy, length |
| Budget exercise | Finance, grants, programme management | Accuracy, eligibility of costs, donor rules |
| Translation | Roles with language requirements | Accuracy, terminology |
| Case study or in-tray | Management roles | Prioritisation, judgement, safeguarding awareness |
| Presentation | Senior roles | Structure, time, answering questions |
| Psychometric or language test | Some UN agencies, EU | Practice familiarity |

## 2. Prepare

1. Build a **practice test** that matches the type, the sub-sector and the country context, with a time limit and a 5-point scoring grid. Do not give the answer first.
2. After the client answers (the coach pastes it), score it against the grid and give specific feedback: structure, use of the ToR or question words, evidence, sector terms, length, time.
3. Give a **one-page cheat sheet** for the type (for example the logframe structure, SMART indicators, OECD DAC criteria, sitrep format).
4. Remind: tests are usually done without AI; check the employer's rules. Practice is for the client's own skill.
